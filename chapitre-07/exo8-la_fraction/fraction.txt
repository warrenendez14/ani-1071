Essais :
1/2 + 1/3 = 5/6 1/2 - 1/3 = 1/6 1/2 * 1/3 = 1/6 1/2 / 1/3 = 3/2 4/8 = 1/2 1/-2 = -1/2

Égalités :
1/2 == 2/4 : 1 (vrai) 1/2 == 1/3 : 0 (faux)

Dénominateur nul :
Fraction(1,0) affiche Erreur. La division par Fraction(0,1) affiche aussi Erreur. Le dénominateur nul est interdit pour éviter une fraction invalide.

Invariant :
Le constructeur réduit chaque fraction avec le PGCD et rend le dénominateur positif. Ainsi, les fractions égales ont les mêmes numérateur et dénominateur. L'opérateur == compare directement les deux membres.
